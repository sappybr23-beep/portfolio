# Портфолио — руслан ан

Статический сайт (HTML/CSS/JS), сверстанный по макетам Paper «Jolly lantern».
Адаптивен: десктоп (sticky-сайдбар + лента) и мобильная версия (одна колонка).

## Структура

```
portfolio-site/
├── index.html              # Главная: профиль + лента проектов
├── about.html              # Обо мне: опыт, методы, инструменты
├── projects/
│   ├── glamour-pay.html    # Кейс: криптокошелёк Glamour.Pay
│   ├── study-ai.html       # Кейс: AI-репетитор STUDY.AI
│   ├── abricos.html        # Кейс: маркетплейс «абрикос»
│   └── concepts.html       # Плакаты, 3D, концепты, фирстиль
├── css/styles.css          # Дизайн-система (токены, компоненты)
├── js/                     # (зарезервировано)
└── assets/img/             # 85 изображений, выгружены из Paper
```

## Как открыть локально

```bash
cd portfolio-site
python3 -m http.server 8777
```

Затем открыть http://localhost:8777

(Можно и просто открыть `index.html` в браузере — всё работает без сервера.)

## Дизайн-система

- Шрифт: **Roboto Mono** (400 / 500), подключён с Google Fonts
- Текст: 16px, line-height 1.4, letter-spacing −0.02em
- Цвета: текст `#1E1E1E`, фон `#FFFFFF` (главная/обо мне) и `#F8F8F8` (кейсы), рамки `rgba(30,30,30,.08)`
- Радиусы: 8 / 16 / 24 / 32 / 48 px
- Приглушённый текст — через `.muted` (50%) и `.muted-56` (56%)

## ⚠️ Что нужно заменить на свои ссылки

Сейчас это плейсхолдеры (`href="#"` / `https://t.me/`):

- **CV** — ссылка на резюме (во всех кнопках «CV»)
- **написать в тг** — `https://t.me/<ваш_ник>` (главная, обо мне, кейсы)
- **Макет в Фигме — смотреть тут** — ссылки на Figma в кейсах
- **Посмотреть работы** (фотогалерея в «обо мне»)

Проекты **lately** и **на грядке** помечены «[скоро]» и пока без отдельных страниц —
как и в макете. Когда будут готовы, добавить страницы в `projects/` и сделать карточки ссылками.
